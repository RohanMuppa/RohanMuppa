# hey, i'm rohan 👋

i build things that make AI actually useful.

right now i'm deep into **agentic systems**. not just chatbots, but AI that can reason, use tools, and take action. the kind of stuff where you give it a goal and it figures out the path. i think we're at the beginning of something big here.

### what i'm exploring

- **tool-using AI**: giving models the ability to interact with real systems (databases, APIs, file systems)
- **RAG architectures**: because LLMs shouldn't have to memorize everything
- **MCP (Model Context Protocol)**: building bridges between AI and the tools we already use
- **multi-agent coordination**: when one agent isn't enough

### what i believe

AI is most interesting when it's not just answering questions but *doing things*. the gap between "here's information" and "i did that for you" is where the real value is.

i like building for specific problems. campus navigation, local government transparency, course planning. generic tools are fine, but tools built for a community hit different.
